# Architecture diagrams

ไฟล์ `.drawio` เป็นเอกสารที่แก้ไขด้วย diagrams.net/draw.io:

- `flow.drawio`: แสดง workflow/data flow ตามภาพประกอบ
- `mini.drawio`: ภาพสถาปัตยกรรมฉบับย่อ

แผนภาพไม่ได้ถูกโหลดหรือประมวลผลโดย Docker Compose หรือ application; ตรวจเทียบกับ `compose.yml` และ README หลักเมื่อสถาปัตยกรรมเปลี่ยน

# Grafana dashboards

- `dashboards.yml` กำหนด dashboard provider และตำแหน่งไฟล์ที่ Grafana โหลด
- `database_explorer.json` นิยาม dashboard สำหรับสำรวจข้อมูลฐานข้อมูล
- `system_logs.json` นิยาม dashboard สำหรับดู log

JSON dashboards เป็น Grafana provisioning assets ไม่ใช่ source code ที่ backend โหลด.

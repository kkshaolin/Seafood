# Utility Scripts

โฟลเดอร์รวมสคริปต์ตัวช่วย (Utility Scripts) สำหรับผู้ดูแลระบบหรือนักพัฒนา

- **`download_dataset.py`**: สคริปต์สำหรับโหลด Dataset ตัวอย่างมาไว้ใน Local Storage
- **`export_openapi_to_csv.py`**: ส่งออกโครงสร้าง API (OpenAPI schema) ออกมาเป็นรูปแบบ CSV
- **`generate_label_studio_token.py`**: สคริปต์สำหรับสร้าง Token อัตโนมัติให้ระบบ Label Studio
